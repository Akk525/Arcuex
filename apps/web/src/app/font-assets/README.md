# Self-hosted fonts

IBM Plex Sans, IBM Plex Mono, and Inter Tight are vendored so the production
build can run without fetching Google Fonts. The unmodified font files and
their SIL Open Font Licenses come from
[google/fonts at cc5661d43cd4f9aad5567033a8e15ca28dc35c86](https://github.com/google/fonts/tree/cc5661d43cd4f9aad5567033a8e15ca28dc35c86/ofl).

- `IBM-Plex-Sans.ttf` is `ibmplexsans/IBMPlexSans[wdth,wght].ttf`.
- The two IBM Plex Mono files are the regular and medium faces under `ibmplexmono/`.
- `Inter-Tight.ttf` is `intertight/InterTight[wght].ttf`.
